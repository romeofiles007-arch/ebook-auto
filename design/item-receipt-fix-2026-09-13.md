# หยุดขณะยืนยันการส่งคำสั่งรายชิ้น

## หลักฐานของงานจริง

ภาพ Studio จากผู้ใช้แสดงเวลา 13:30:35: ช่องพิมพ์เปลี่ยนหรือเริ่มตอบ แต่จับข้อความที่ส่งไม่ได้ จึงหยุดโดยไม่ส่งซ้ำ หลังจากนั้นเวลา 13:31:34 ตัวทำต่อเลิกลองหลังติดซ้ำสามครั้ง การปิด CEO เป็นข้อความอธิบายทางกู้ที่ไม่มี ไม่ใช่สาเหตุแรก

อ่านเฉพาะ DOM ของแท็บ ChatGPT ที่ผู้ใช้เปิดอยู่ พบข้อความล่าสุดมี message id `12632ccd-d13d-469d-aad5-a6c64d3f87d7` พร้อมป้าย `Pasted text(20260913-063002).txt` และ `Document` ก่อนข้อความ “เขียนกลอน 1 ชิ้น…” ข้อความจริงอยู่ใน `[data-testid="collapsible-user-message-content"]`

วิธีเดิมเทียบต้นข้อความจากทั้ง user node จึงไม่ตรงกับต้น prompt วิธีอ่านเฉพาะเนื้อหา bubble ตรงกับ prompt ได้ คำตอบล่าสุดมีทั้ง `<<<ITEM 1.1>>>` และ `<<<END 1.1>>>` และไม่พบ Stop answering ณ เวลาตรวจ ไม่ได้ส่งคำสั่งหรือกดหยุดใน ChatGPT

## การแก้

- เพิ่มตัวเลือก itemReceipt เฉพาะ Machine ของ contentMode=items ที่ไม่ขอภาพ และปุ่มเขียนรายชิ้นใหม่
- Transport ส่งตัวเลือกนี้ให้ adapter เฉพาะเมื่อเปิดใช้อย่างชัดเจนและไม่ใช่ภาพ
- Adapter อ่านเนื้อหา bubble เฉพาะเมื่อเปิดตัวเลือก ทั้งการเก็บ snapshot ก่อนส่งและการหา receipt หลังส่ง ใช้ snapshot แบบเดียวกันจึงไม่หลงนับข้อความเก่าซ้ำ
- ยังคงต้องตรงกับ prompt และเป็นข้อความใหม่ตาม message id/ลำดับ/จำนวน ไม่ใช้เพียง composer ว่างหรือมีปุ่ม Stop เป็นหลักฐานว่าส่งสำเร็จ
- Caller อื่นใช้การอ่านแบบเดิมทั้งหมด ไม่เปิด CEO ไม่เพิ่ม retry ไม่ข้ามด่านคุณภาพ

## ทดสอบ

- ชุดรวมหลังแก้ matcher: 428/428 ผ่าน
- เพิ่มทดสอบการส่งตัวเลือกจาก Machine และ transport แล้วรันส่วนที่เกี่ยวข้อง: 21/21 ผ่าน
- ครอบคลุมไฟล์นำหน้า ข้อความเก่าที่ห้ามรับซ้ำ ไฟล์เปล่าที่ไม่มี bubble ข้อความคนละอัน bubble ที่พับ ข้อความเก่าถูกถอดจาก DOM และเส้นทางของนิยาย/ร้อยแก้ว/ภาพที่ไม่เปิดตัวเลือก

## สิ่งที่ยังไม่เสร็จบนเครื่องผู้ใช้

โค้ดแก้ใน workspace แล้ว แต่ไม่ได้โหลดเข้า extension ที่เปิดอยู่หรือกู้สถานะเล่มจริง เครื่องมือ browser ปฏิเสธการเข้าหน้า chrome-extension ของ Studio และห้ามใช้ทางเลี่ยง จึงไม่อ้างว่ากู้เล่มที่ค้างสำเร็จ การยืนยันกับ DOM ข้างต้นเป็นการอ่าน ChatGPT ไม่ใช่การติดตั้ง adapter ใหม่ในแท็บนั้น

เมื่อไม่มีงาน ChatGPT กำลังตอบ ให้ผู้ใช้รีโหลดส่วนขยายและแท็บ ChatGPT แล้วเปิดเล่มเดิมทำต่อ ไม่ต้องสร้างเล่มใหม่
