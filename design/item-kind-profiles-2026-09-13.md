# ร่าง: โปรไฟล์ประเภทชิ้น (โหมดรายชิ้นเท่านั้น)

สถานะ: **ร่างให้อ่านก่อน ยังไม่ได้แก้โค้ด**
ขอบเขต: `core/items.js` · `core/item-quality.js` · ส่วนรายชิ้นใน `typeset/template.js` · ช่องตั้งค่ารายชิ้นใน Studio — ไม่แตะร้อยแก้ว/นิยาย

---

## 1. ปัญหาที่แก้

ตอนนี้ 6 ประเภทต่างกันแค่ "คำอธิบาย 1 บรรทัด + ความยาว + จำนวนต่อข้อความ" ที่เหลือใช้ร่วมกันหมด:

| ขั้น | ตอนนี้ | ผลที่เห็นในเล่มจริง |
|---|---|---|
| การ์ดผู้เขียน | แม่แบบสารคดี "ผู้เรียบเรียงที่อธิบายด้วยตัวอย่าง · อธิบายเหตุผลก่อนให้คำแนะนำ" | คำคมกลายเป็นคำอธิบาย กลอนกลายเป็นคำสอน |
| วางหมวด | "angle = หมวดนี้พูดถึงมุมไหน" | หมวดเป็นแนวคิด ชิ้นในหมวดจึงขยายแนวคิด |
| เขียนชิ้น | ข้อห้ามล้วน ไม่มีคำสั่งเรื่องฝีมือ ไม่มีตัวอย่าง | "ถ้า… อาจ… แต่ถ้า…" ซ้ำทั้งเล่ม · ตัวเลขแทนภาพ |
| กันซ้ำ | 40 ตัวอักษรแรกของ 30 ชิ้นล่าสุด | ซ้ำโครงประโยคได้ไม่จำกัด |
| บรรณาธิการ | ตรวจกติกา (ซ้ำ ฉันทลักษณ์ ตรงหัวข้อ) | ชิ้นแบนแต่ถูกกติกาผ่านหมด |
| จำนวน | หน้า × ชิ้นต่อหน้า | ชื่อเล่ม "120 บทกลอน" แต่เขียน 240 บท |

## 2. โครงใหม่: หนึ่งประเภท = หนึ่งโปรไฟล์

```js
ITEM_PROFILES[kind] = {
  label, core,            // แก่นของชิ้นในหนึ่งประโยค
  speaker,                // ผู้พูด (ใช้แทนการ์ดผู้เขียนแบบสารคดี)
  themeShape,             // หมวดของประเภทนี้คืออะไร
  length, perTurn,
  craft: [],              // คำสั่งฝีมือ (สิ่งที่ต้องมี)
  avoid: [],              // สิ่งที่ทำให้ชิ้นแบน (เฉพาะประเภท)
  good: [], flat: [],     // ตัวอย่างดี / แบน พร้อมเหตุผลสั้น ๆ
  review: [],             // เกณฑ์ของบรรณาธิการ (เพิ่มจากกติกาเดิม)
  layout: { align, sizePt, heading },
  images: { perItems, style },
  fitsTopic,              // ใช้เตือนตอนตั้งค่า
}
```

ทุกขั้นอ่านจากโปรไฟล์นี้ที่เดียว เพิ่มประเภทใหม่ในอนาคต = เพิ่มโปรไฟล์หนึ่งก้อน

## 3. ส่วนร่วมทุกประเภท

### 3.1 การ์ดเสียงผู้พูด (แทนการ์ดผู้เขียนสารคดี — เฉพาะรายชิ้น)

```
กำหนด "เสียงผู้พูด" ของหนังสือรวม{label} "{title}"
แก่นของเล่ม: {topic} · ผู้อ่าน: {audience}
ประเภทนี้ผู้พูดเป็น: {speaker}
ไม่ต้องสร้างประวัติบุคคลจริง ไม่อ้างอาชีพหรือความสำเร็จ
ตอบ JSON: {
  "speaker": "ผู้พูดคือใคร อยู่ในช่วงไหนของเรื่องนี้ (1 ประโยค)",
  "world": "ภาพ/ของ/สถานที่ที่ผู้พูดหยิบมาใช้บ่อย 5-8 อย่าง เฉพาะกับหัวข้อนี้",
  "register": "ระดับภาษา เช่น พูดกับตัวเอง / พูดกับเพื่อน / เล่าเบา ๆ",
  "never": ["คำหรือสำนวนที่ผู้พูดคนนี้ไม่มีวันใช้ 4-6 คำ"]
}
```

`world` สำคัญที่สุด — เป็นคลังภาพของเล่ม เช่นเล่มหมดไฟ: "จอมือถือตอนตีสอง · แชตลูกค้าที่ยังไม่ตอบ · กาแฟแก้วที่สาม · ปฏิทินคอนเทนต์ที่ว่าง · ไฟวงแหวนที่ยังเปิด"

### 3.2 วางหมวด

เปลี่ยน `angle` เป็นสองช่อง และให้หมวดเรียงเป็นเส้นทาง:

```json
{ "n": 1, "title": "…", "moment": "ผู้อ่านอยู่ในช่วงไหน/รู้สึกอะไรตอนเปิดหมวดนี้", "images": ["ภาพหลักของหมวด 3-4 อย่าง"] }
```

+ กติกา: "หมวดต้องเรียงตามลำดับที่ผู้อ่านเดินผ่านจริง ({themeShape}) หมวดสุดท้ายต้องพาไปจุดที่เบากว่าหมวดแรก"

### 3.3 จำนวนชิ้นจากชื่อเล่ม

ถ้าหัวข้อ/ชื่อมีตัวเลข + หน่วยของประเภท (เช่น "120 บทกลอน", "80 คำคม") → ใช้ตัวเลขนั้นเป็นจำนวนชิ้น แล้วคำนวณหน้าจากมัน
ถ้าไม่ตรงกับจำนวนหน้าที่ตั้ง → เตือนในหน้าตั้งค่า: "ชื่อบอก 120 บท แต่ 120 หน้า × 2 ต่อหน้า = 240 บท — ใช้ 120 บท (60 หน้า) หรือแก้ชื่อ?"

### 3.4 โครง prompt เขียนชิ้น (ทุกประเภทใช้โครงนี้)

```
เขียน{label} {count} ชิ้น สำหรับหมวด "{theme.title}" ในหนังสือ "{title}"

ผู้พูด: {voice.speaker} · ระดับภาษา: {voice.register}
ช่วงของหมวดนี้: {theme.moment}
ภาพที่หยิบใช้ได้: {theme.images + voice.world}

แก่นของ{label}: {core}
ความยาว: {length}

สิ่งที่ชิ้นที่ดีต้องมี
{craft…}

สิ่งที่ทำให้ชิ้นแบน — ห้าม
{avoid…}
- ห้ามใช้คำ: {voice.never}

ตัวอย่าง (อย่าลอกเนื้อหา ดูแค่ระดับฝีมือ)
ดี: {good[0].text} — {good[0].why}
แบน: {flat[0].text} — {flat[0].why}

ใช้ไปแล้วในเล่ม ห้ามซ้ำทั้งใจความ ภาพหลัก และโครงประโยค
{avoid list: "1.3: ภาพ=กาแฟแก้วที่สาม · โครง=ไม่ใช่…แต่คือ…"}

(รูปแบบคำตอบ <<<ITEM>>> เหมือนเดิม)
```

รายการกันซ้ำเปลี่ยนจาก "40 ตัวอักษรแรก" เป็น **ภาพหลัก + โครงประโยค** ของชิ้นที่ใช้ไปแล้วในหมวดเดียวกัน — ให้บรรณาธิการเป็นคนสกัดสองค่านี้ตอนตรวจ (เพิ่ม 2 ช่องใน verdict ไม่เพิ่มข้อความ)

### 3.5 โครง prompt บรรณาธิการ

คงกติกาเดิมไว้ทั้งหมด แล้วเพิ่ม:

```
เกณฑ์ฝีมือของ{label}
{review…}
- ถ้าชิ้นถูกกติกาแต่แบน (อ่านแล้วไม่มีอะไรติดใจ) ให้ needs_revision และบอกว่าขาดอะไร

ตอบ: {"verdicts":[{"id","verdict","reason","image":"ภาพหลักของชิ้น 2-4 คำ","shape":"โครงประโยค เช่น ถ้า…แต่…"}]}
```

และตรวจทั้งชุด: ถ้าโครงประโยคเดียวกันเกิน 3 ชิ้นในชุด → ชิ้นที่เกินได้ needs_revision

## 4. โปรไฟล์ทั้ง 6 ประเภท

> ตัวอย่างทั้งหมดผมเขียนขึ้นใหม่ ยกเว้นที่ระบุว่ามาจากเล่มจริง — **ตรงนี้ต้องการสายตาคุณมากที่สุด** ถ้าตัวอย่าง "ดี" ยังไม่ดีพอ prompt จะดึงคุณภาพลงตาม

### 4.1 คำคม

| | |
|---|---|
| แก่น | ความจริงหนึ่งข้อที่คนรู้สึกแต่ไม่เคยพูดออกมา พูดให้คมในประโยคเดียว |
| ผู้พูด | คนที่ผ่านเรื่องนี้มาแล้ว พูดจากข้างใน ไม่ใช่ผู้เชี่ยวชาญมองจากข้างนอก |
| หมวด | ความจริงคนละด้านของหัวข้อ เรียงจากที่เจ็บสุดไปที่ปล่อยวางได้ |
| ความยาว | 1–2 บรรทัด ไม่เกิน 90 ตัวอักษร · 15 ชิ้นต่อข้อความ |

craft
- หนึ่งชิ้นหนึ่งความคิด อ่านรอบเดียวแล้วจำได้
- มีภาพหรือของจริงอย่างน้อยหนึ่งอย่างจากโลกของผู้พูด
- จังหวะสองจังหวะ: ตั้ง → พลิก หรือ ภาพ → ความหมาย
- กล้าพูดตรง ไม่กั๊ก

avoid
- คำกั๊ก: อาจ · ควร · บางที · ไม่จำเป็นต้อง · ไม่ควรถูกแปลว่า
- ตัวเลข สถิติ ตาราง (เว้นแต่ตัวเลขนั้นคือภาพ เช่น "ตีสอง")
- อธิบายเหตุผล / "เพราะ…" ต่อท้าย
- คำให้กำลังใจลอย ๆ ที่ย้ายไปหนังสือเล่มไหนก็ได้

ตัวอย่าง
- ดี: "ยอดวิวไม่เคยถามว่าคืนนั้นคุณนอนกี่ชั่วโมง" — ภาพจริง พูดสิ่งที่คนทำคอนเทนต์รู้สึกแต่ไม่พูด
- ดี: "คุณไม่ได้ขี้เกียจ คุณแค่ใช้แรงของพรุ่งนี้ไปตั้งแต่เมื่อวาน"
- แบน (จากเล่มจริง): "ถ้าลดงานแล้วแรงกลับมา ปัญหาอาจอยู่ที่ปริมาณ แต่ถ้าลดแล้วงานเดิมยังหนักเหมือนเดิม ต้องดูวิธีทำงานด้วย" — เป็นคำแนะนำ มีคำกั๊ก ยาวเกิน ไม่มีภาพ

review: คมไหม · มีภาพไหม · มีคำกั๊กไหม · เป็นคำแนะนำหรืออธิบายแทนคำคมไหม

layout: จัดกลาง · ~14pt · หน้าละ 1–2 · ภาพ: น้อย (หน้าคั่นหมวดเท่านั้นเป็นค่าเริ่ม)

### 4.2 คำให้กำลังใจ

| | |
|---|---|
| แก่น | พูดกับ "คุณ" ตรง ๆ ในวันที่แย่ ให้รู้สึกว่ามีคนเห็น |
| ผู้พูด | เพื่อนที่นั่งอยู่ข้าง ๆ ไม่ใช่โค้ชบนเวที |
| หมวด | ช่วงอารมณ์ของผู้อ่าน: วันที่หมดแรง → วันที่ลังเล → วันที่เริ่มใหม่ |
| ความยาว | 1–3 บรรทัด ไม่เกิน 110 ตัวอักษร · 15 ชิ้นต่อข้อความ |

craft
- ยอมรับความรู้สึกก่อน แล้วค่อยให้สิ่งเล็ก ๆ ที่ถือไปได้
- สิ่งที่ให้ต้องเล็กและจริง (พักได้ · ช้าได้ · วันนี้พอแค่นี้)
- ใช้ "คุณ" หรือ "เธอ" ให้ตรงกับระดับภาษาของเล่ม ทั้งเล่มใช้แบบเดียว

avoid
- สัญญาผลลัพธ์ (สำเร็จแน่ · ทุกอย่างจะดีขึ้น)
- สั่งให้คิดบวก / "อย่าท้อ"
- บอกว่าความรู้สึกของผู้อ่านผิด

ตัวอย่าง
- ดี: "วันนี้คุณไม่ต้องเก่งกว่าเมื่อวาน แค่ยังอยู่ตรงนี้ก็พอแล้ว"
- แบน: "จงเชื่อมั่นในตัวเอง แล้วคุณจะประสบความสำเร็จอย่างแน่นอน" — สัญญาเกินจริง ย้ายไปเล่มไหนก็ได้

review: อบอุ่นแต่ไม่ลอย · ไม่สัญญาผล · ไม่ตัดสินความรู้สึก · สรรพนามคงที่

layout: จัดกลาง · ~14pt · ภาพ: บรรยากาศอบอุ่น 1 ต่อ 24

### 4.3 สุภาษิต/ข้อคิด

| | |
|---|---|
| แก่น | ข้อคิดที่ห่อด้วยภาพเปรียบเทียบจากของรอบตัว จำได้เพราะภาพ |
| ผู้พูด | ผู้ใหญ่ช่างสังเกต พูดน้อย |
| หมวด | ด้านของชีวิตที่หัวข้อแตะ (งาน · คน · ตัวเอง · เวลา) |
| ความยาว | 1–2 บรรทัด ไม่เกิน 100 ตัวอักษร · 15 ชิ้นต่อข้อความ |

craft
- ภาพเปรียบ 1 ภาพ ใช้ของที่ทุกคนเคยจับ (น้ำ แก้ว เชือก ไฟ เทียน)
- โครงคู่ขนานได้ (ภาพ ↔ ชีวิต) แต่ห้ามใช้โครงเดิมเกิน 3 ชิ้นต่อหมวด
- ปล่อยให้ผู้อ่านเชื่อมเอง ไม่อธิบายภาพ

avoid
- สอนตรง ๆ ไม่มีภาพ · ภาพเปรียบที่ช้ำ (ชีวิตคือการเดินทาง)

ตัวอย่าง
- ดี: "แก้วที่เต็ม เติมอีกหยดก็ล้น คนที่เต็มกำลัง รับอีกงานก็พัง"
- แบน: "การพักผ่อนเป็นสิ่งสำคัญต่อชีวิตของทุกคน" — ไม่มีภาพ เป็นประโยคในตำรา

review: มีภาพเปรียบไหม · ภาพช้ำไหม · อธิบายภาพเองไหม

layout: จัดกลาง · ~13.5pt · ภาพ: ภาพเปรียบ 1 ต่อ 24

### 4.4 กลอน

| | |
|---|---|
| แก่น | ช่วงเวลาหนึ่งที่มีภาพ มีความรู้สึกเคลื่อน ตามฉันทลักษณ์กลอนแปด |
| ผู้พูด | "ฉัน" ในเรื่อง พูดจากในเหตุการณ์ ไม่ใช่ผู้เล่าที่สรุปบทเรียน |
| หมวด | เส้นทางอารมณ์ตามลำดับ (เล่มลมหนาว: เคยรัก → เหนื่อย → ยังอยากรัก) |
| ความยาว | กลอนแปด 2 บท (8 วรรค) · **5 ชิ้นต่อข้อความ** |

craft
- ฉันทลักษณ์กลอนแปด: วรรคละ 7–9 พยางค์ · คำท้ายวรรคสดับ สัมผัสคำที่ 3 หรือ 5 ของวรรครับ · คำท้ายวรรครับ สัมผัสคำท้ายวรรครอง · คำท้ายวรรครอง สัมผัสคำที่ 3 หรือ 5 ของวรรคส่ง · คำท้ายวรรคส่งบทแรก สัมผัสคำท้ายวรรครับบทที่สอง
- บทแรกวางภาพ/เหตุการณ์ บทที่สองให้ความรู้สึกเคลื่อน วรรคส่งสุดท้ายเป็นจุดที่ค้างในใจ
- ใช้ภาพจากคลังของหมวดอย่างน้อย 2 ภาพ

avoid
- วรรคที่เป็นคำสอน ("ต้องรู้จัก…" "จงทำใจ…")
- สัมผัสฝืนจนความหมายแปลก / คำเติมเพื่อให้ครบพยางค์ (แล้ว · นั้น · เอย)
- ศัพท์ออฟฟิศ/ตัวเลขที่ทำให้กลอนกลายเป็นรายงาน (จากเล่มจริง: "ลองดูตารางว่าเราพร้อมไหม")

ตัวอย่าง (บทเดียว)
- ดี:
  ```
  ลมหนาวแตะขอบหน้าต่างบางเบา
  เหมือนมือเราที่เคยกุมคืนก่อน
  แก้วกาแฟสองใบยังวางซ้อน
  ทั้งที่ตอนนี้ฉันอยู่ลำพัง
  ```
  — ภาพจริง (หน้าต่าง แก้วสองใบ) ความรู้สึกมาจากภาพ ไม่ต้องบอกว่าเหงา
- แบน:
  ```
  ความรักต้องใช้เวลาอย่ารีบร้อน
  ค่อยค่อยสอนใจตนให้มั่นคง
  ```
  — สอน ไม่มีภาพ

review: ตรวจสัมผัสทีละตำแหน่งตามข้างบน (ระบุคำที่ผิด) · มีภาพไหม · สอนไหม · คำเติมไหม · บทที่สองเคลื่อนจากบทแรกไหม

**คำถาม:** ต้องการกลอนแปดอย่างเดียว หรือเปิดให้เลือก กลอนสี่ / กลอนแปด ในหน้าตั้งค่า? (ปนกันในเล่มเดียวดูไม่เป็นเล่ม)

### 4.5 บทกวีสั้น (กลอนเปล่า)

| | |
|---|---|
| แก่น | ภาพเดียวที่ตัดบรรทัดให้จังหวะทำงาน ไม่บังคับสัมผัส |
| ผู้พูด | ผู้สังเกตเงียบ ๆ |
| หมวด | ช่วงเวลาของวัน/ฤดู หรือห้อง/สถานที่ |
| ความยาว | 3–6 บรรทัด บรรทัดละสั้น · 8 ชิ้นต่อข้อความ |

craft
- ภาพเดียว ชัด เฉพาะเจาะจง
- การตัดบรรทัดต้องมีเหตุผล: บรรทัดสุดท้ายพลิกหรือขยายความหมาย
- ใช้คำน้อยที่สุด

avoid
- ร้อยแก้วที่แค่กดขึ้นบรรทัดใหม่ · คำนามธรรมล้วน (ชีวิต ความหวัง ความฝัน) โดยไม่มีภาพ

ตัวอย่าง
- ดี:
  ```
  ไฟในห้องยังเปิด
  แต่คนในห้อง
  ดับไปตั้งแต่สี่ทุ่ม
  ```
- แบน: "ชีวิตนั้นแสนเหนื่อยล้า / แต่เราต้องสู้ต่อไป / เพื่อวันพรุ่งนี้" — นามธรรม ไม่มีภาพ ตัดบรรทัดไม่มีผล

review: มีภาพเดียวชัดไหม · บรรทัดสุดท้ายทำงานไหม · ถ้าต่อเป็นประโยคเดียวแล้วไม่เสียอะไร = แบน

### 4.6 เคล็ดลับสั้น

| | |
|---|---|
| แก่น | สิ่งเดียวที่ทำได้ภายในวันนี้ พร้อมเหตุผลครึ่งประโยค |
| ผู้พูด | คนทำงานเดียวกันที่ลองมาแล้ว |
| หมวด | ปัญหา → วิธีแก้ เรียงจากเร่งด่วนไปยั่งยืน |
| ความยาว | หัวข้อ 1 บรรทัด + เนื้อ 2–3 บรรทัด · 10 ชิ้นต่อข้อความ |

craft
- หัวข้อขึ้นต้นด้วยกริยา ("ปิดแจ้งเตือนหลังสามทุ่ม")
- เนื้อบอก: ทำอย่างไร (ตัวเลข/เวลา/ปุ่มใช้ได้ที่นี่) + ได้อะไร
- หนึ่งชิ้นหนึ่งการกระทำ

avoid
- ควรจัดการเวลาให้ดี (กว้างจนทำไม่ได้) · หลายขั้นในชิ้นเดียว · ขัดกับชิ้นอื่น

ตัวอย่าง
- ดี:
  ```
  ปิดแจ้งเตือนหลังสามทุ่ม
  ตั้งโหมดห้ามรบกวน 21:00–08:00 ลูกค้าที่ทักตอนดึกรอถึงเช้าได้ แต่สมาธิพรุ่งนี้ของคุณรอไม่ได้
  ```
- แบน: "ควรจัดการเวลาให้ดี เพื่อไม่ให้เหนื่อยเกินไป" — ไม่มีอะไรให้ทำ

review: ทำได้วันนี้ไหม · กว้างเกินไหม · ขัดกับชิ้นอื่นไหม · มีหัวข้อที่เป็นกริยาไหม

## 5. เตือนเมื่อประเภทไม่เข้ากับหัวข้อ

ในหน้าตั้งค่า เมื่อเลือกประเภทแล้วพิมพ์หัวข้อ — ตรวจแบบง่ายในเครื่อง ไม่เสียข้อความ:
- หัวข้อมีคำเชิงปฏิบัติ (ขาย · ทำคอนเทนต์ · วิธี · เทคนิค · รายได้ · ธุรกิจ) + ประเภท กลอน/บทกวีสั้น/คำคม →
  "หัวข้อนี้เป็นเรื่องปฏิบัติ ถ้าเลือกคำคม ผลมักออกมาเป็นคำแนะนำย่อ — ถ้าอยากได้สิ่งที่ทำตามได้ เลือก 'เคล็ดลับสั้น' · ถ้าอยากได้คำคมจริง ระบบจะบังคับห้ามคำแนะนำ"
- ไม่บล็อก แค่เตือน (เล่ม "หมดไฟ แต่ยังไม่หมดทาง" จะโดนเตือนตรงนี้)

## 7. ขอให้ตัดสิน

1. ตัวอย่าง "ดี" ในแต่ละประเภทใช้ได้ไหม — ถ้ามีตัวอย่างที่ชอบจากหนังสือจริง (ไม่ต้องยาว) ส่งมาได้ ผมจะเขียนตัวอย่างในแนวเดียวกัน ไม่ลอก
2. กลอน: กลอนแปดอย่างเดียว หรือให้เลือกกลอนสี่/แปด
3. เคล็ดลับสั้นมีหัวข้อตัวหนา — โอเคไหม (ต้องเปลี่ยนรูปแบบคำตอบของประเภทนี้)
4. จำนวนชิ้นจากชื่อเล่ม: ใช้ตัวเลขในชื่อเป็นหลัก หรือแค่เตือน
5. กลอน 5 ชิ้นต่อข้อความ (ช้าขึ้นเท่าตัว คุณภาพดีขึ้น) — รับได้ไหม
